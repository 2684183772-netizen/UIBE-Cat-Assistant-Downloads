# UIBE Cat Assistant Downloads

UIBE Cat Assistant（AI 惠知猫咪桌宠）的公开下载仓库。

本仓库只提供安装包、校验值和发布说明，不包含桌宠源代码。桌宠单击后会打开已部署的惠知 AI 校园信息检索网站：<https://huizhi-ai.coze.site>。

## 下载

公开发布完成后，请从 GitHub Releases 下载适合自己系统的文件：

- macOS：`UIBE Cat Assistant-0.1.0-mac-universal.dmg`
- macOS ZIP：`UIBE Cat Assistant-0.1.0-mac-universal.zip`
- Windows 安装版：`UIBE Cat Assistant-0.1.0-Setup-x64.exe`
- Windows 便携版：`UIBE Cat Assistant-0.1.0-Portable-x64.exe`

下载后请使用同一 Release 中的 `SHA256SUMS.txt` 检查文件完整性。

## 系统要求

- macOS 13 Ventura 或更高版本，支持 Apple Silicon 和 Intel Mac。
- Windows 10/11 64 位。
- 需要网络连接以访问惠知 AI 网站。

## 安全说明

当前 `v0.1.0` 是未使用商业代码签名证书的比赛展示版本：

- macOS 可能提示开发者无法验证或应用未公证。请先核对 SHA-256；确认来源可信后，可参考 [Apple 官方安全说明](https://support.apple.com/en-us/102445)。
- Windows 可能显示“未知发布者”或 SmartScreen 提示。Microsoft 建议谨慎运行不知名应用，参见 [Microsoft 官方说明](https://support.microsoft.com/en-us/office/protect-my-pc-from-viruses)。
- 不建议关闭 Gatekeeper、SmartScreen 或系统防病毒功能。

已安装版本不会自动更新。新版本发布后需要重新下载安装。
